# A Little Apology

A tiny static web page (plain HTML, CSS and JavaScript — no build step).

## Files
- `index.html` — the page
- `style.css` — styles
- `main.js` — hearts, runaway "No" button, popup
- `crying-kitten.jpg` — image

## Live site
Hosted with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
